# 心术

> 天下交易，三分技术，七分心术。

作者把心术（心态控制）看作占 70% 权重的部分，是对读者「最高的要求」：技术没学好可以靠勤奋补，心术不行，一念之差就会造成不可挽回的损失。书中的心术散落在各章之间，这里集中整理。

## 心态准备 I：把自己当菜鸟

- 在市场面前我们都渺小得像尘埃。你的想法左右不了市场，你的推理也算不出市场的走势。
- 问题不在于你没做出正确判断，而在于**你以为自己能做出正确判断**。
- 要做的事按顺序：先冷静下来并保持冷静（不去听、不去看、不去问）→ 让每次交易越来越理性，像机器人一样 → 靠知识和认知提高正确的概率 → 最后成为掌控者。

## 心态准备 II：利用时间，而不是对抗时间

- 「不以物喜，不以己悲」谁都做不到，完全去欲望化不现实。能做的是：**无论高兴还是难过，保持平和、意识清晰**。
- 情绪起伏的根源是**时间**：人的时间有限，总想在有限的生命里得到更多。不要试图克服时间带来的压力，要学会**利用时间**：
  - **分配时间**：开单只要 10 秒，盯盘能耗掉 7×24 小时，最值得花时间的是学习和分析。
  - **掌握时刻**：量能和 Fib 都给不出明确方向时，**放弃这次机会**。那不是机会，只是无聊时打发时间。

## 十条心术

| # | 要点 |
|---|---|
| 一 | 学更多技术不会让正确率飞跃，**冷静地分析和开单**才是盈利的关键。像豹子一样等待、观察，再出击 |
| 二 | 自然交易是为了**预测未来，不是复盘历史**。判断正确只是开始，**平仓获利离场才是终点** |
| 三 | 选择技术分析，前提是相信 **K 线里已经包含了所有市场信息**。不坚定就会一直慌乱 |
| 四 | **多即是少**：不要操作太多标的、太多平台，不要获取太多信息 |
| 五 | 快速翻转的概率极低，像德州扑克里的皇家同花顺。**彻底断绝抄底抄顶的念头** |
| 六 | **别急，等着。等着，别动。** 太安静而不安时，深呼吸。下一次机会很快会来 |
| 七 | 短期赚几十倍的人常见，能守住利润离场的作者从没见过。交易的目的是**稳稳地获得可支配的利润**，不是追求刺激 |
| 八 | 不要被盈利目标约束而急功近利。**在时间与收益之间，收益永远第一**。开平仓、仓位控制、止损全部做对，才是一次完整合格的交易 |
| 九 | 「**不希望它跌**」和「**不认为它会跌**」是两码事。任何时候都不该有前一种心态，二级市场是没有希望的地方 |
| 十 | 你以为极低概率的突发事件不会发生在你身上，但碰上一次就可能满盘皆输。**开单前先设止损** |

## 市场之手与「马后炮」

- **市场之手**：市场有一只无形的手，一直按着你，不让你盈利。身边暴富的故事只会让你羡慕、心乱。交易要从**最大程度的敬畏**出发。
- **马后炮**：「低买高卖」「突破压力位就开单」「确认回踩」「不要逆势」「到了 x 价位就可能去 y」—— 说的人不用负责，也没人记得。不要花时间在这些话上，也不要被资讯牵着走。

## 自然交易与趋势

- 自然交易理论**不适合判断大趋势**，因为大趋势「并不自然」：它是 50:50 的博弈，事后看到的抓住大趋势的人，多半只是幸运。
- 理论能帮你找到正确的开仓点位、时间和方向，但**按不住你的手**，只有自己能按住自己。
- 不要被一次放大的单一事件影响判断。黑天鹅不可预测，理论也判断不了，能做的是严格控制仓位，获得可控范围内的盈利。

## 绝对逻辑与随机博弈

这是书中唯一一章完整的思维理论。

**绝对逻辑**：一副手套分别放进两个盒子，打开一个是左手，另一个一定是右手 —— 但这个结论成立的前提是：确定放进去的是一对（而不是两只一样的）、确定第一个盒子真的打开了。

- 任何科学理论都建立在有限的事实上，没有绝对正确。
- 判断涨跌时，要做的不是综合各方消息推论，而是**检查自己的逻辑里有没有遗漏的关键前提**。
- 交易中**不存在绝对理性的判断**，只存在**绝对理性的开单和平仓**。世上没有能永远判断对方向的人，但有能做到绝对理性交易的人。

**随机博弈**：

- 市场是随机博弈，**没有任何力量在针对你**。结果从没被预先设定，只是事后人们才觉得像是被安排好的。
- 认识到随机性，才能控制好心态，不被他人左右。

## 追逐与停留

### 追逐

追涨杀跌本身没问题，只要在自己的仓位管理体系内。问题是大多数人的追逐不理性：时间和空间都被压缩，眼里不再有 Fib、量能和任何指标，只剩「这次不能再踏空」—— 也就是「上头了」。

书中的定义：

> **追逐 = 高倍杠杆 × 大仓位 × 无法控制的操作**，结果必然是归零离场。

作者讲了自己 2014 年的经历：在 BTC 一轮行情的末段，因为私人原因想「一次实现资产快速膨胀」，在接近顶点处开多，止损后又在更低处开多，反复被止损，每天开单量急剧上升，直到发现亏掉了总仓位的 40%。期间每次都告诫自己「这次止损就不再开」，但每次都没做到。

**如果忍不住要追**：最多试 **3 次**，3 次都错就停下来，冷静旁观。下一次机会可能在半个月或一个月后，不要急。

对照本仓库的标签：这就是情绪循环里的 `FOMO` → `chased` → `revenge` → `overtrading`（见 [02-emotions](../psychology/02-emotions.md)、[05-mistakes](../psychology/05-mistakes.md)）。「最多 3 次」可以写进自己的停手规则。

### 停留

「停留」可以浅层理解为**拿住单子**的技巧，也可以深层理解为**驻足静思**的心术。它的本质是**低仓位、低杠杆**，和追逐正好相反。资金来源的问题见 [仓位控制](./05-position.md#交易资金从哪里来)。

- 不必操作多个标的，做好一个就够；不必因为错过某次暴涨暴跌惋惜，也不必因为某次亏损茶饭不思。
- **交易是为了更好地生活，不要让生活被交易绑架。**
