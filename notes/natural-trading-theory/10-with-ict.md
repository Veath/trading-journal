# 与 ICT 对照及记录方式

> 本篇是我把书中内容和 ICT 放在一起的对照，**不是书中内容**。书中没有提到 ICT。

## 根本差异

| | ICT | 自然交易理论 |
|---|---|---|
| 方向从哪来 | HTF 结构 + 流动性（DOL） | 成交量的多空能量 |
| 位置从哪来 | PD Array（FVG / OB / Breaker）、Premium / Discount、OTE | Fib 回撤 + 引力 |
| 时间从哪来 | Killzone、Silver Bullet 等固定时段 | Fib 趋势时间（由走势本身投射） |
| 周期 | 日内为主，HTF 定方向、LTF 入场 | 4H 为主，判断 2–4 周 |
| 指标 | 不用指标 | 只用 Fib 和成交量，其他指标一律抛弃 |
| 支撑阻力 | 用前高前低作为流动性 | 书中明确抛弃支撑阻力 |

两套体系都**不用传统指标**，都强调「等待」和「心态」。但书中要求抛弃 MA、MACD、RSI，和本仓库 [RSI](../rsi/00-overview.md)、[EMA](../ema/00-overview.md)、[MACD](../macd/00-overview.md) 笔记的思路是冲突的 —— 不要在同一笔交易里混用两套判断标准，否则复盘时说不清是哪个依据起了作用。

## 可以互相参照的地方

| 自然交易理论 | ICT 里相近的概念 | 区别 |
|---|---|---|
| 0.5 次引力 | [Premium / Discount](../ict/03-pd-arrays.md) 的 50% 分界 | ICT 用 50% 划分只买 / 只卖的区域；书中把它当作「价格经过但不停留」的次引力 |
| 0.618 / 0.382 强引力 | [OTE](../ict/03-pd-arrays.md)（62%–79% 回撤） | 画法方向相反（见 [Fib 回撤](./02-fib-retracement.md#方向)）；OTE 是入场区间，书中强调 0.618 / 0.382 不是拐点 |
| 量能放大点（引力点） | 位移（Displacement） | ICT 看的是价格的位移和留下的 FVG；书中看的是成交量 |
| 相对强势 K 柱（长影线） | 扫流动性后的拒绝 | ICT 关心影线扫掉了哪一侧流动性；书中关心影线反映的多空强弱 |
| 追逐 = 高杠杆 × 大仓位 × 失控 | `FOMO`、`chased`、`revenge` | 书中的「最多试 3 次」可以直接作为停手规则 |

## 在日志里怎么记录

交易模板里 `strategy` 已经有「自然交易理论」这个取值：

```yaml
strategy: 自然交易理论
timeframe: 4H
tags: [ntt-energy-shift, ntt-fib-0618, ntt-time-0618]
```

建议的 `tags`（自定，书中没有）：

| 标签 | 含义 |
|---|---|
| `ntt-energy-shift` | 入场依据包含量能转换（一方衰退、另一方接管） |
| `ntt-fib-0618` / `ntt-fib-0382` / `ntt-fib-05` | 入场位置在哪条 Fib 回撤线附近 |
| `ntt-time-0618` / `ntt-time-line` | 入场在 Fib 趋势时间 0.618 / 其他竖线前后 2 根 K 线内 |
| `ntt-candle-absolute` / `ntt-candle-relative` | 用单根 K 柱的绝对 / 相对强势择时 |
| `ntt-chase` | 追逐单，用于检验「最多 3 次」 |

ICT 交易只是参考了 Fib 位置时，保持 `strategy: ICT`，在 `tags` 里标记即可。

## 用数据检验书中的主张

书中最核心的可检验主张是「基础阶段判断正确率 60%+」。积累样本后可以对比：

- `strategy: 自然交易理论` 的胜率、平均 R，和 ICT 交易对比；
- 三要素都满足（三个 `ntt-` 标签齐全）和只满足一两个的交易对比；
- 手绘量能练习的「下一根量柱」预测命中率（见 [能量](./01-energy.md#基础练习手绘量能波动曲线)）。

注意胜率不等于书中说的「判断正确率」：方向判断对了，也可能因为入场位置或止损被扫出而亏损。两者都值得记录。
