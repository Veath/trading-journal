# HTF Bias 与自上而下分析

Bias 回答一个问题：**今天价格更可能去上方还是下方的流动性？**
方向错了，入场再精确也难以盈利 —— 用仪表盘的「HTF Bias 是否正确」维度检验这一点。

## 自上而下流程

| 周期 | 看什么 |
|---|---|
| Monthly / Weekly | 大区间的 Premium / Discount；最近的 HTF FVG、旧高旧低；本周可能的 DOL |
| Daily | 昨天扫了哪侧流动性？日线 FVG / OB 在哪？今天的 DOL（PDH 还是 PDL）？ |
| 4H / 1H | 日内结构、关键 PD Array、Asia / London 区间 |
| 15m / 5m | 时段内的 MSS、FVG |
| 1m（入场） | 精确入场、止损位置 |

[教程](https://chanlunpp.org/basics-ict) 7.2 的补充：

- 三个周期分工：**最高的定方向，中间的管仓位，最低的扣扳机**。常见组合：日内用 日线 / 1H / 5m；波段用 周线 / 日线 / 1H；超短用 1H / 15m / 1m
- **找到即停**：找入场 FVG 时从 5m 开始，依次看 4m、3m、2m、1m，哪一层先出现合格的缺口就用哪一层；到 1m 都没有，当天放弃

## 每日 Bias 的几个问题

1. **价格刚从哪里来？** 昨天/前几天扫了 BSL 还是 SSL？回补了哪个 HTF FVG？
2. **价格在区间的哪一半？** 处于 HTF 折价区 → 偏多；溢价区 → 偏空
3. **下一个明显的流动性在哪？** 那就是 DOL
4. **日线 K 线可能怎么走？** 结合 Power of 3：今天的开盘之后，先往哪边操纵？

教程 7.1 把叙事压缩成三问：**什么刚被拿走？它会把价格引向哪里？什么还没被拿走？**（最后一个就是下一个 DOL）

- Bias 以日线为主，预测范围 **不超过 5 个交易日**
- 价格在区间 50% 附近时不定 bias
- 日线在关键位出现犹豫 K 线（小实体、长影线），是次日反转的辅助信号，但必须结合位置看
- 一天只朝一个方向找单
- 入场前按顺序检查五件事：HTF 方向明确 → 目标池明确 → 处在 Killzone 内 → 价格在正确一侧的 PD Array 上 → LTF 出现了扫流动性、MSS、FVG

### 前日高低框架（教程 7.7）

- 默认目标：看涨日看 PDH，看跌日看 PDL，可以延伸到前三天的高低
- **Failure to Displace**：碰到 PDH 但没有向上位移，说明上面的任务完成了，目标切换到 PDL
- **Inside Day**：昨天的区间被前天包住，两天都没扫外部流动性，今天扫 PDH 或 PDL 的概率更高
- 理想的看涨剧本：在 Midnight Open 下方扫掉 PDL，反转后目标 PDH

## IPDA 数据范围

ICT 认为算法回看 **20 / 40 / 60 个交易日** 的价格范围。这些区间的高低点是重要的流动性参考。

教程 5.12 的用法：只数交易日，框出 20 / 40 / 60 日三层高低，把 60 日区间对半切，标出溢价和折价里的 PD Array。最近一次 HTF MSS 之后的 20–60 天里，预期会有一次明显的动作；三层的两侧都被扫过之后，大行情的目标要去 60 日之外找。回看窗口不给买卖点，只回答「什么时候该警觉」。

## Bias 的失效

提前写下「什么情况说明我错了」，例如：

- 价格收盘突破了作为依据的 HTF PD Array
- 应该是 DOL 的一侧之外，反方向的流动性先被大幅突破且没有反转

在 [每日日志](../../journal/templates/day.md) 中记录 `dailyBias`，交易后在交易记录中填写 `biasCorrect`。

## 无 Bias 日

看不清的时候，**neutral 也是一种 bias**：不交易或只做最高质量的 setup。
