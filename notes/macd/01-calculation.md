# MACD 计算与组成

## 公式（默认参数 12, 26, 9）

```
MACD 线    = EMA(close, 12) − EMA(close, 26)
Signal 线  = EMA(MACD 线, 9)
柱状图     = MACD 线 − Signal 线
```

EMA 的计算见 [EMA 计算](../ema/01-calculation.md)。

| 组成 | 中文常用名 | 含义 |
|---|---|---|
| MACD 线 | DIF / 快线 | 短期均线相对长期均线的偏离：> 0 表示短期均价高于长期均价 |
| Signal 线 | DEA / 慢线 | MACD 线的平滑 |
| 柱状图（Histogram） | MACD 柱 | 快线与慢线的距离，反映 **动能的变化**（MACD 线的「加速度」） |

> 有些国内软件把柱状图乘以 2 显示，形状不变，只是数值不同。

## 需要记住的性质

- **无界**：NQ 上 MACD 可以是 ±50，EURUSD 上可能是 ±0.0005；同一品种不同价格阶段也不可比
- **双重滞后**：MACD 线基于 EMA 已经滞后，Signal 又是 MACD 的 EMA，金叉死叉往往在行情走出一段后才出现
- **柱状图领先于交叉**：柱体开始缩短 = MACD 线开始向 Signal 靠拢，交叉往往随后发生
- 只用收盘价，看不到影线（扫流动性的长影线在 MACD 上几乎没有反映）
