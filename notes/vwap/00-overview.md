# VWAP 学习路线

VWAP（Volume Weighted Average Price，成交量加权平均价）是 **从某个起点开始、所有成交的平均成本**。机构常用它衡量执行质量（买在 VWAP 下方 = 执行得好），因此它也是日内多空双方都在看的参考价。

> VWAP 回答的是「从锚点到现在，市场的平均成本在哪里，价格是被接受在它上方还是下方」。

## 学习方法

1. **先固定锚点**。日内统一用同一个 session 锚点，否则不同天的 VWAP 无法比较。
2. **配合 [FRVP](../frvp/00-overview.md) 一起看**。两者都基于成交量：VWAP 是「平均成本」，Volume Profile 是「成本分布」。
3. **用日志验证**。用到 VWAP 的交易在 `tags` 里标记（如 `tags: [vwap]`），积累样本后对比。
