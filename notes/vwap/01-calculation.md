# VWAP 计算、锚点与标准差带

## 公式

每根 K 线取典型价 `TP = (high + low + close) / 3`（也有平台用 `hlc3` 以外的源，默认基本都是 hlc3）：

```
VWAP = Σ(TP × volume) / Σ(volume)      // 从锚点累加到当前
```

- 累加从 **锚点** 开始，到下一个锚点清零
- 越往后，单根 K 线对 VWAP 的影响越小 —— 开盘早段 VWAP 移动快，午后几乎是一条平线

## 锚点（Anchor）

| 锚点 | 用途 |
|---|---|
| **Session（日）** | 最常用的日内 VWAP |
| Week / Month | 周 / 月的平均成本，看更大级别的接受区 |
| **Anchored VWAP（AVWAP）** | 从某个特定事件开始算：重要高 / 低点、财报、FOMC、跳空 |

### 期货的 session 选择（以 NQ / ES 为例）

- CME 电子盘每天 **18:00 ET** 开始新的交易日；TradingView 等平台的 Session VWAP 默认从这里开始（含亚洲、伦敦时段）
- 只看现货开盘后的行为时，可以用 **09:30 ET** 锚定的 AVWAP（RTH VWAP）
- 两者在 NY 时段可能差很多，记录和复盘时说清楚用的是哪一个

### Anchored VWAP 的锚点选择

AVWAP 的意义是「从这个事件之后进场的所有人的平均成本」，所以锚点应该是 **真正改变了供需的点**：

- 引发位移和 MSS 的摆动高 / 低点
- 扫掉关键流动性（PDH / PDL、周高低）的那根 K 线
- 新闻 / 开盘跳空的第一根 K 线

## 标准差带（Bands）

```
方差 = Σ(volume × (TP - VWAP)²) / Σ(volume)
带   = VWAP ± k × √方差        // k 常用 1、2、3
```

- 价格分布近似正态时，±1σ 包含大部分成交，±2σ 已经是延伸，±3σ 罕见
- 带宽本身反映当天波动：开盘窄、趋势展开后变宽
- 不同平台的带宽算法（成交量加权 vs 简单标准差、百分比带）可能不同，以自己使用的平台为准

## 需要记住的性质

- VWAP **依赖成交量数据**：外汇现货没有集中成交量（用的是 tick volume），加密货币各交易所成交量不同，参考价值会打折扣
- VWAP 是 **滞后** 的，它告诉你平均成本在哪里，不预测方向
