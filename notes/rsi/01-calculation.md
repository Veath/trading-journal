# RSI 计算与参数

## 公式

对每根 K 线计算收盘价变化 `Δ = close - prevClose`：

- 上涨幅度 `U = max(Δ, 0)`
- 下跌幅度 `D = max(-Δ, 0)`

```
RS  = 平均 U / 平均 D
RSI = 100 - 100 / (1 + RS)
```

- 平均 D 为 0（一直涨）时 RSI = 100；平均 U 为 0 时 RSI = 0
- RSI = 50 意味着这段时间涨跌力度相等

## Wilder 平滑

Wilder 原版用的不是简单平均，而是一种指数平滑（RMA / SMMA）：

```
首个平均值 = 前 n 根的简单平均
之后：avg_t = (avg_{t-1} × (n - 1) + 当前值) / n
```

等价于 α = 1/n 的 EMA。所以 RSI 会 **记住很久以前的数据**：同一根 K 线上，加载 200 根历史和 2000 根历史算出的值可能有细微差别。不同平台的 RSI 对不上时，先检查平滑方式和数据起点。

## 参数

| 参数 | 特点 |
|---|---|
| **14**（默认） | Wilder 原始参数，最常用；多数书籍和教程的阈值都基于 14 |
| 2–9 | 更敏感，频繁触及极值，常用于短线均值回归 |
| 21–25 | 更平滑，信号少，适合看大级别动能 |

- 周期越短，越容易到 70/30 以外；改周期就要同步改对阈值的预期
- **数据源**：一般用收盘价；不同周期（1m / 5m / 1H）的 RSI 是完全不同的数据，判断时说清楚是哪个周期的 RSI

## 需要记住的性质

- RSI 是 **有界** 的：强趋势里它会长时间贴着 70 以上或 30 以下，这不是反转信号
- RSI 只用收盘价，**看不到影线**：一根长影线扫流动性的 K 线，RSI 可能几乎不动
- RSI 只反映 **相对** 涨跌，不含成交量
