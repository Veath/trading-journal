# Keyshotvv：交易规则

> 从他 2026 年的公开发言提炼，全部为转述。**↗** 链接到对应原帖；没有链接的条目来自较短的回复。他自己说过体系还在调整，规则也可能随之变化。

## 核心四步

1. **找关键点位**：在你做的级别上，找出有流动性的位置（他常用 50% 回撤、HTF 摆动点、等高 / 等低）
2. **等价格清扫（sweep）** 这个位置
3. **观察价格反应** 是否符合预期
4. **有反应就进，没有就不进**

关键点位的识别是主观的，取决于你做的级别和你设定的 DOL。[↗](https://x.com/Keyshotvv/status/2110376502948946339)

## 一、方向：看大做大

- 方向看 **日线和 4H**：一眼看上去是涨就是涨，是跌就是跌。[↗](https://x.com/Keyshotvv/status/2092992686295048459)
- 短线也要用日线定方向。[↗](https://x.com/Keyshotvv/status/2034456358645563509)
- 想做多，就只认日线级别的低点，其他小级别信号一律屏蔽，不要在小级别里来回绕。[↗](https://x.com/Keyshotvv/status/2111116850658673055)
- 1H 处于空头趋势时，不要指望 1H 一个三段上涨就直接反转。
- 示例模型（做多）：日线先大涨一波 → 4H / 1H 出现积累 → 积累区出现 **假跌破** → 进场。这是 **顺势**；如果积累先上去扫了 EQH 你去做空，那是 **逆势**。[↗](https://x.com/Keyshotvv/status/2110649613506244894)

## 二、流动性与关键点位

- **经典的海龟汤要求多个等高 / 等低点**，而不是单一的高低点被清扫。[↗](https://x.com/Keyshotvv/status/2092982433004359836) [↗](https://x.com/Keyshotvv/status/2092982599828611313)
- 「差不多等高 / 等低」就可以；反例是 **通道和楔形**。[↗](https://x.com/Keyshotvv/status/2094667300700061778)
- **通道 = 趋势**，用流动性逻辑一定要回避逆着通道做；想参与就等 **右侧** 结构出来。[↗](https://x.com/Keyshotvv/status/2111819239971782931)
- 震荡下跌中留下的每一个摆动点，都是未来上涨的燃料。[↗](https://x.com/Keyshotvv/status/2112883658021552245)
- **把所有突破都假想成假突破，真突破不做。**[↗](https://x.com/Keyshotvv/status/2114015048511459504)
- 一个高胜率的进场场景：下跌中继形态的假突破，在 **CHOCH 之后顺势** 进场；止损扛不住就说明判断错了。[↗](https://x.com/Keyshotvv/status/2112924037613764872)
- 流动性和「假突破」不是一回事：理解不够深，关键点位就找不准。[↗](https://x.com/Keyshotvv/status/2113574721703035229)

## 三、ICT 工具的取舍

| 工具 | 他的态度 |
|---|---|
| FVG | 只是 **价格力度的表现**，不认为有其他价值 [↗](https://x.com/Keyshotvv/status/2103442126629679495) |
| CISD | 本级别 CISD = 次级别 MSS |
| 50% / 斐波 | PA 和 ICT 都常看 50%，斐波常看 0.618 [↗](https://x.com/Keyshotvv/status/2110022096801980531) |
| SMT | **建议别看**：做 NQ 就别看 ES，做黄金别看白银，做 EU 别看 GU；直接从流动性本质制定策略 [↗](https://x.com/Keyshotvv/status/2105561595384623260) |
| 季度理论、TGTSF | 放弃了，容易先入为主，忽视走势本身 [↗](https://x.com/Keyshotvv/status/2096406629751427128) |
| 均线 | 不再用于入场；大级别仍会看，或作为最简单的定方向方法 |
| MACD | 抛弃，用 PA 形态代替 [↗](https://x.com/Keyshotvv/status/2024725797500862582) |
| 「几推几推」 | 别给自己上枷锁 |

对 ICT 的总体态度：不讨论谁借鉴谁，只看自己能得到什么，有用就行。[↗](https://x.com/Keyshotvv/status/2103428011957837857)

## 四、周期与进场

- 纳指日内看 **1m / 5m**；波段看 **1H + 5M**。[↗](https://x.com/Keyshotvv/status/2031177611704152365)
- 1H 给信号，1 分钟只是为了找个好位置进场。
- **不要在盘中做决定，一切等 K 线收盘**（例如等 5M、1H 收盘）。[↗](https://x.com/Keyshotvv/status/2110041074052034645)
- **大小周期嵌套**：如果小周期进场嵌套在大周期逻辑里，就用 **大周期的流动性出场**。[↗](https://x.com/Keyshotvv/status/2110650500324700182)
- 出现完整结构才盯盘，平时大致看一眼就行。
- 抄底胜率低：只用很小的仓位，走好了再加。[↗](https://x.com/Keyshotvv/status/2056275070813970944)

## 五、止损

- **固定百分比止损**，单笔风险 **0.5%–2%**。[↗](https://x.com/Keyshotvv/status/2034456151035871306)
- 开仓即挂好止损和止盈，也会视情况提前走。
- 止损放在 **结构上有意义的位置**：
  - 放在 CRT 下方就足够，保守一点放 BISI 下方 [↗](https://x.com/Keyshotvv/status/2047195117304570356)
  - 做 BTC 那笔：止损要放在 **周一高点** 才是有效止损 [↗](https://x.com/Keyshotvv/status/2110384746186547446)
  - 点评别人：进场没问题，但止损应该放在 **日线最低**，为了提高盈亏比拉近止损是错的 [↗](https://x.com/Keyshotvv/status/2111861275643052224)

## 六、止盈与管理

- 目标是 **流动性**：DOL、HTF 摆动点、上周高点、周线低点等。
- 常见路径：**1H 内部流动性 → 外部流动性**。[↗](https://x.com/Keyshotvv/status/2055542217721500000)
- 现阶段 **放弃高盈亏比、保证胜率**，目标给到 HTF 摆动点。[↗](https://x.com/Keyshotvv/status/2050025345534013699)
- **分批止盈**；目标难判断就拿到 **2R**。[↗](https://x.com/Keyshotvv/status/2034247661684150484)
- 到了 TP1 却没设保本是败笔，正在改进移动止损和保本的习惯。[↗](https://x.com/Keyshotvv/status/2033455557848469834) [↗](https://x.com/Keyshotvv/status/2040988801879924768)
- 出现大级别信号 K（如 4H 巨大信号 K）时，部分止盈是合理的。[↗](https://x.com/Keyshotvv/status/2112545991069221001)
- 日内单不过周末，睡前全平。[↗](https://x.com/Keyshotvv/status/2028390392463507562) [↗](https://x.com/Keyshotvv/status/2033439082337185990)
- 日线 + 周线级别清扫后进场的单子，可以几天不看盘，给价格充分的波动时间。[↗](https://x.com/Keyshotvv/status/2110223955869286811)

## 七、品种与时段

- 品种偏好：**外汇 > 美股 > 贵金属 > 加密**，加密基本可以放弃。[↗](https://x.com/Keyshotvv/status/2038095000303788397)
- **只做固定的几个品种**。[↗](https://x.com/Keyshotvv/status/2110040924705489104) 外汇方面先删了欧元、后来连澳元也不看，只看纽元。
- 按品种选时段（北京时间）：[↗](https://x.com/Keyshotvv/status/2100990536215879920)
  - 日经：上午 8–10 点找机会，没有就不做
  - 纳指：亚盘不做，做伦敦时段
  - 黄金：亚盘、伦敦盘做，美盘不做
- 周一早上开盘后的流动性非常好。
- 币圈边缘市场流动性不足，不建议做。

## 用这些规则检查一笔交易

| 检查项 | 对应日志字段 |
|---|---|
| 日线 / 4H 方向清楚吗？顺势还是逆势？ | `htfBias` |
| 关键点位是什么？是不是多个等高 / 等低，而不是通道 / 楔形？ | `liquiditySweep` `pdArrays` |
| 清扫之后有没有出现预期的反应（CHOCH / MSS / CISD）？等 K 线收盘了吗？ | 正文「交易中」 |
| 这是假突破还是在追真突破？ | `setup` `mistakes` |
| 止损在结构位置上，还是为了盈亏比硬拉近的？ | `stop` |
| 目标是流动性吗？到了 TP1 有没有分批、保本？ | `target` `r` |
| 品种和时段在自己的固定清单里吗？ | `symbol` `session` |
| 单笔风险在 0.5%–2% 之内吗？ | `size` |
