# EMA 学习路线

EMA（Exponential Moving Average，指数移动平均）是 **给近期价格更高权重** 的均线，比 SMA 更快跟上价格。本笔记统一使用 **21 / 55 / 100 / 200** 四条 EMA。

> 均线回答的是「趋势方向和强度」以及「价格相对平均成本的位置」，不回答流动性在哪里、什么时候入场。

## 学习方法

1. **参数固定不改**。四条均线就用 21 / 55 / 100 / 200，所有周期、所有品种一致。
2. **先看排列，再看回踩**。排列决定方向，回踩只是位置。
3. **用日志验证**。用到 EMA 的交易在 `tags` 里标记（如 `tags: [ema-21-pullback]`、`tags: [above-ema200]`），积累样本后对比。
4. 与 [MACD](../macd/00-overview.md) 一起学：MACD 就是由两条 EMA 构造出来的。
