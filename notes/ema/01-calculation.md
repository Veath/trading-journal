# EMA 计算与四条均线的分工

## 公式

```
α     = 2 / (n + 1)
EMA_t = α × close_t + (1 − α) × EMA_{t-1}
```

- 初值一般取前 n 根收盘价的 SMA
- n = 21 时 α ≈ 0.091，n = 200 时 α ≈ 0.01：周期越长，单根 K 线影响越小，均线越平滑也越滞后
- 和 RSI 的 Wilder 平滑一样，EMA 会「记住」很久以前的数据：历史加载太短时，200 EMA 可能和平台显示的不一致

### EMA vs SMA

| | EMA | SMA |
|---|---|---|
| 权重 | 越近越大（指数衰减） | 窗口内相等 |
| 反应 | 快，回撤时更早被触及 | 慢 |
| 窗口外的数据 | 仍有很小影响 | 完全丢弃，旧数据移出时均线会「跳」 |

## 21 / 55 / 100 / 200 的分工

| EMA | 角色 | 常见用法 |
|---|---|---|
| **21** | 短期动能 | 强趋势中的浅回撤位；价格持续在 21 一侧 = 动能强 |
| **55** | 中期趋势 | 正常回撤位；21 与 55 的相对位置定义中期方向 |
| **100** | 中长期趋势 | 深回撤位；趋势是否「伤筋动骨」的分界 |
| **200** | 长期趋势 / 牛熊分界 | 价格在上方只考虑做多为主，下方做空为主；被广泛关注的位置 |

- 21 和 55 是斐波那契数，100 和 200 是机构和媒体常用的整数周期
- 同一组 EMA 在不同周期上含义不同：日线 200 EMA 是大级别牛熊线，5m 200 EMA 只是日内的长期均线。说 EMA 时要带上周期，如「1H EMA 55」

## 需要记住的性质

- 均线是 **滞后** 指标：它确认趋势，不预测转折
- 震荡市里均线会缠绕、频繁交叉，这时排列和交叉信号几乎没有意义
- 均线「支撑 / 阻力」是一个 **区域**，不是精确价格，价格刺穿一点再收回很常见
