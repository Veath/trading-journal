# 情绪识别与应对

情绪本身不是问题，**没有察觉到情绪就做决定** 才是问题。记录情绪的目的是让它可见、可统计。

## 情绪词汇表

在 `emotions.before / during / after` 中使用统一的词，才能分组统计：

| 标签 | 状态 | 典型表现 |
|---|---|---|
| `calm` | 平静 | 按清单执行，接受任何结果 |
| `confident` | 自信 | 对分析有把握，但仍守规则 |
| `anxious` | 焦虑 | 盯盘过紧、频繁看盈亏、想提前离场 |
| `fearful` | 恐惧 | 不敢扣扳机、错过符合条件的入场 |
| `FOMO` | 害怕错过 | 追价入场、没等回撤、放宽条件 |
| `greedy` | 贪婪 | 不按计划止盈、加仓、移远目标 |
| `frustrated` | 沮丧 | 连续亏损后烦躁、怀疑系统 |
| `revenge` | 报复 | 亏损后立刻想「赚回来」，加大仓位 |
| `euphoric` | 亢奋 | 连赢后过度自信、放松标准 |
| `bored` | 无聊 | 没有 setup 也想交易 |
| `tired` | 疲惫 | 睡眠不足、注意力不集中 |

## 常见情绪循环与应对

### 恐惧 → 错过 → FOMO

1. 亏损后害怕，不敢做符合条件的单 → 记录为 `status: missed`
2. 看到错过的单跑到目标，后悔
3. 下一次追价入场 → `mistakes: [FOMO, chased]`

**应对**：用数据说话。统计错过的机会的潜在 R，它会提醒你「不扣扳机也是成本」；同时规定：错过就是错过，不追。

### 亏损 → 报复交易 → 更大亏损

**应对**：
- 硬规则：连亏 2 笔或达到每日最大亏损立即停止
- 每笔亏损后强制离开屏幕 10–15 分钟
- 在 `mistakes` 中如实记录 `revenge`，仪表盘「错误的代价」会显示它的真实成本

### 连赢 → 过度自信 → 放松标准

**应对**：
- 盈利后同样执行完整的入场前检查清单
- 盈利日达到目标后停止
- 关注 `euphoric` / `confident` 状态下的期望值是否下降

### 持仓焦虑 → 提前离场

**应对**：
- 入场前写好目标和管理规则，持仓中只执行规则
- 设置好止损 / 止盈后减少看盘
- 检查「盈利单兑现率」，用数据看提前离场让你少赚了多少

## 情绪检查（每笔交易前 30 秒）

1. 我现在的情绪是哪个标签？
2. 我的身体状态如何？（紧张、心跳、呼吸）
3. 这笔交易如果亏损 1R，我能平静接受吗？
4. 如果不能 → 降低仓位或放弃这笔

## 用数据检验

一段时间后，在仪表盘按「交易前情绪」分组：

- 哪种情绪下你的期望值最高？
- 哪种情绪下最好不要交易？

把结论写进 [交易计划](./06-trading-plan.md)，例如「`tired` 或 `revenge` 状态不交易」。
