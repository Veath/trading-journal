# 交易日常流程

稳定的流程能减少临场决策，从而减少情绪干扰。

## 盘前（交易开始前 30–60 分钟）

运行 `pnpm new:day` 创建当日日志，然后完成：

1. **状态检查**：睡眠（`sleep`）、情绪状态（`mood`）、生活中是否有影响注意力的事
2. **新闻**：当天的高影响数据和时间（`news`）
3. **HTF 分析**：Weekly → Daily → 1H，写下 `dailyBias` 和 DOL
4. **关键位置**：标出 PDH/PDL、Asia/London 高低点、HTF PD Arrays
5. **今天只做什么、不做什么**：具体到模型和时段
6. **风控上限**：`maxTrades`、`maxLossR`

> 状态评分 ≤ 2 时，考虑当天只观察不交易，或减半风险。

## 盘中

- 只在计划好的时段、计划好的模型出现时交易
- 每笔入场前过一遍 [检查清单](../ict/checklist.md)
- 入场后立刻截图，简单记下当时的想法和情绪（之后补全日志）
- 达到每日限制立即停止

## 盘后（收盘后 15–30 分钟）

1. 补全每笔交易的日志：出场价、R、截图、`followedPlan`、`mistakes`、`emotions.after`
2. 记录错过的机会（`status: missed`）
3. 在每日日志写盘后复盘：今天守住纪律了吗（`rulesFollowed`）？最好和最差的一个决定？
4. 写下 **明天要改进的一件事** —— 只写一件

## 每周复盘（周末）

打开仪表盘，选择「近 7 天」：

- [ ] 期望值、胜率、盈亏比与长期数据相比如何？
- [ ] 按计划执行率是多少？违反计划的交易贡献了多少 R？
- [ ] 本周最贵的错误是什么？
- [ ] 哪个 setup / 时段表现最好、最差？
- [ ] 回看所有截图：A+ 的交易长什么样？
- [ ] 下周的一个过程目标

## 每月复盘

选择「本月」，在更大样本上：

- 某个 setup 是否需要停止或调整规则？
- 情绪 / 信心与结果的关系有没有规律？
- 风险参数是否需要调整（参考最大回撤和最长连亏）？
- 更新 [交易计划](./06-trading-plan.md)
