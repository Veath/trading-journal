# Trade Psychology & Effective Journaling

交易心理与有效日志的学习笔记。核心思想：

> **你无法控制单笔交易的结果，但可以控制决策过程。日志的作用是把「过程」变成可测量的数据。**

## 在本项目中的对应

| 心理 / 日志概念 | 记录位置 | 仪表盘中的统计 |
|---|---|---|
| 盘前准备、状态检查 | `journal/days/` 每日日志 | 每日日志页 |
| 交易前 / 中 / 后情绪 | 交易 `emotions` | 按「交易前情绪」分组 |
| 是否遵守计划 | `followedPlan` | 按计划执行率；按计划 vs 违反计划 |
| 错误类型 | `mistakes` | 错误的代价 |
| 决策质量（与结果无关） | `grade` | 按评级分组 |
| 信心 | `confidence` | 按信心分组 |
| 犹豫、错过 | `status: missed` | 错过的机会 |
| 每日纪律 | 每日日志 `rulesFollowed` | 每日日志页 |

> 本目录 1–6 是基于交易心理学常见原则整理的通用笔记，并非该课程内容的摘录；课程本身的要点请记录在 [课程笔记](./course-notes.md)，并据此修订其他章节。
