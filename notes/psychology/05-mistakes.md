# 错误分类

日志 `mistakes` 字段使用以下统一标签。名称统一，仪表盘的「错误的代价」才能准确汇总。

## 入场前

| 标签 | 定义 |
|---|---|
| `no-setup` | 没有符合任何已定义模型的 setup 就入场 |
| `ignored-bias` | 逆着自己的 HTF bias 交易 |
| `outside-killzone` | 在计划之外的时段交易 |
| `news` | 在高影响数据发布前后违规交易 |
| `bad-state` | 明知状态不佳（疲惫、情绪化）仍交易 |

## 入场

| 标签 | 定义 |
|---|---|
| `FOMO` | 因害怕错过而入场，没有等待确认 |
| `chased` | 追价：没等回撤进入 PD Array 就入场 |
| `early-entry` | 条件未全部满足（如 MSS 未确认）就提前入场 |
| `late-entry` | 犹豫导致入场过晚，R:R 变差 |
| `oversize` | 仓位超过规则规定的风险 |
| `no-stop` | 入场时没有设置止损 |

## 持仓与出场

| 标签 | 定义 |
|---|---|
| `moved-stop` | 把止损向不利方向移动（扩大风险） |
| `early-be` | 过早把止损移到保本，被正常回撤扫出 |
| `early-exit` | 没有到目标或失效条件，因情绪提前平仓 |
| `held-loser` | 失效条件出现后仍持有亏损仓位 |
| `moved-target` | 因贪婪把目标移远，最终回吐利润 |

## 交易之后

| 标签 | 定义 |
|---|---|
| `revenge` | 为了弥补亏损而进行的交易 |
| `overtrading` | 超过每日最大交易笔数 |
| `broke-daily-limit` | 达到每日最大亏损后继续交易 |

## 使用原则

- 一笔交易可以有多个标签
- 新增标签前先看能否归入已有标签；确需新增，同时更新本文件
- `followedPlan: false` 的交易通常应该至少有一个错误标签
- 盈利的交易同样要记录错误 —— 「决策错误但盈利」最需要被发现
