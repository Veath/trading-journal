# 统计指标说明

所有指标以 **R 倍数** 为单位：1R = 入场价到止损价的距离（即这笔交易计划承担的风险）。

- 用 R 而不是金额，是因为仓位、品种、点值会变，R 才能让每笔交易公平比较。
- `R = (出场 - 入场) / |入场 - 止损|`，空单取反；分批止盈或移动止损无法用一个出场价表达时，直接在 frontmatter 里写 `r:`。
- `|R| < 0.1` 视为 **保本（BE）**，不计入胜负（阈值见 `src/lib/parse.ts` 的 `BREAKEVEN_THRESHOLD`）。
- 只有 `status: closed` 的交易进入统计；`open` 忽略，`missed` 单独统计为「错过的机会」。

## 结果指标

| 指标 | 公式 | 怎么看 |
|---|---|---|
| 胜率 | 盈 / (盈 + 亏) | 不含保本单；另提供含保本版本 |
| 平均盈利 / 平均亏损 | 盈利单 R 的均值 / 亏损单 R 的均值 | 平均亏损应接近 -1R，明显低于 -1R 说明止损没守住 |
| **盈亏比** | 平均盈利 R / \|平均亏损 R\| | 实际兑现的，不是计划的 R:R |
| 保本胜率 | 1 / (1 + 盈亏比) | 以当前盈亏比，至少要多少胜率才不亏 |
| **胜率优势** | 胜率 − 保本胜率 | > 0 才有正期望；比单看胜率或盈亏比更直接 |
| **期望值** | 所有交易 R 的均值 = 胜率 × 均盈 − 败率 × \|均亏\| | 每做一笔平均赚多少 R，最核心的指标 |
| 利润因子 | 盈利单 R 合计 / \|亏损单 R 合计\| | > 1.5 不错，> 2 很好 |
| 最大回撤 | 累计 R 曲线从峰值到谷底的最大落差 | 决定每笔风险应设多少：例如能承受账户 10% 回撤、历史最大回撤 8R，单笔风险就不该超过约 1% |
| 最长连亏 | 连续亏损笔数（保本单不打断） | 心理承受能力的预演 |
| SQN | √N × 期望值 / R 的标准差 | Van Tharp 的系统质量数：<1.6 差，2–2.5 良好，>3 优秀；样本 < 30 笔参考意义有限 |

## 过程指标（Trade Psychology & Effective Journaling）

结果有运气成分，过程才是能控制的部分。

| 指标 | 含义 |
|---|---|
| 按计划执行率 | `followedPlan: true` 的占比 |
| 按计划 vs 违反计划 | 两组分别的胜率、盈亏比、期望值 —— 用数据证明「守纪律」值多少 R |
| 平均计划 R:R | 入场时设定的 target / stop 距离 |
| 盈利单兑现率 | 盈利单实际 R / 计划 R:R；长期偏低说明总是提前离场 |
| 错误的代价 | 每个 `mistakes` 标签出现的次数和所在交易的 R 合计 |
| 错过的机会 | `status: missed` 的笔数和潜在 R —— 犹豫不决也是成本 |

## 分维度统计

仪表盘可以按以下维度切分，找出真正赚钱的部分、砍掉亏钱的部分：

Setup · 时段 / Killzone · 策略 · 品种 · PD Array · 评级 · 星期 · 方向 · HTF Bias 是否正确 · 交易前情绪 · 信心

例如：
- **评级**：A+ 单的期望值是否明显高于 B/C？如果是，就只做 A 级。
- **时段**：NY AM 和 London 哪个更适合你？
- **交易前情绪**：`FOMO` / `revenge` 状态下的交易期望值是多少？
- **HTF Bias 是否正确**：bias 判断错误时你亏多少？说明要先提升叙事判断。
